# Список Python-библиотек для управления GUI

Для эмуляции ввода текста (включая Unicode) из Python в другие приложения (например, в блокнот), вам понадобятся библиотеки для автоматизации клавиатурного ввода. Вот основные варианты:

## 1. **PyAutoGUI** (Кроссплатформенный, но с некоторыми ограничениями)

```python
import pyautogui
import time

# Дать время для переключения в нужное окно
time.sleep(5)

# Ввод текста с поддержкой Unicode
pyautogui.write('Привет, мир! Hello 世界! 🌍', interval=0.1)

# Или комбинации клавиш
pyautogui.hotkey('ctrl', 'a')  # выделить всё
```

**Особенности:**  
- Работает на Windows, macOS, Linux
- Некоторые символы Unicode могут не поддерживаться в зависимости от ОС
- Может потребоваться установка: `pip install pyautogui`

## 2. **PyGetWindow + PyDirectInput** (Windows, более надежно)

```python
import pygetwindow as gw
import pydirectinput
import time

# Найти окно Блокнота
notepad_windows = gw.getWindowsWithTitle('Блокнот')
if notepad_windows:
    notepad = notepad_windows[0]
    notepad.activate()
    time.sleep(0.5)
    
    # Ввод текста
    pydirectinput.write('Привет, мир! Hello 世界! 🌍')
```

## 3. **keyboard** (Windows/Linux)

```python
import keyboard
import time

time.sleep(3)  # время переключиться в нужное окно

# Напечатать текст
keyboard.write('Привет, мир! Hello 世界! 🌍')
```

```python
    pass

# Более простой способ через буфер обмена
import win32clipboard

def paste_text(text):
    win32clipboard.OpenClipboard()
    win32clipboard.EmptyClipboard()
    win32clipboard.SetClipboardText(text, win32con.CF_UNICODETEXT)
    win32clipboard.CloseClipboard()
    
    # Имитация Ctrl+V
    win32api.keybd_event(win32con.VK_CONTROL, 0, 0, 0)
    win32api.keybd_event(ord('V'), 0, 0, 0)
    win32api.keybd_event(ord('V'), 0, win32con.KEYEVENTF_KEYUP, 0)
    win32api.keybd_event(win32con.VK_CONTROL, 0, win32con.KEYEVENTF_KEYUP, 0)

# Использование
time.sleep(3)
paste_text('Привет, мир! Hello 世界! 🌍')
```

## 5. **ui-automation** (Windows, современный подход)

```python
from uiautomation import WindowControl, SendKeys

# Найти окно Блокнота
notepad = WindowControl(searchDepth=1, Name='Блокнот')
notepad.SetActive()
SendKeys('Привет, мир! Hello 世界! 🌍')
```

## Рекомендации:

### Для быстрого и простого решения:

```python
import pyautogui
import time

# Пауза для переключения в нужное окно
print("Переключитесь в окно Блокнота в течение 5 секунд...")
time.sleep(5)

# Ввод текста
text = "Привет, мир! Hello 世界! 🌍 Emoji: 😀✅🎉"
pyautogui.write(text, interval=0.05)  # interval - задержка между символами
```

### Важные замечания:
1. **Безопасность**: Убедитесь, что нужное окно активно перед вводом
2. **Права доступа**: На macOS/Linux могут потребоваться дополнительные разрешения
3. **Unicode поддержка**: PyAutoGUI и keyboard хорошо работают с Unicode в Windows 10/11
4. **Задержки**: Всегда добавляйте `time.sleep()` перед вводом

**Самый универсальный вариант для начала** - **PyAutoGUI**, так как он:
- Кроссплатформенный
- Простой в использовании
- Хорошо поддерживает Unicode на современных системах
