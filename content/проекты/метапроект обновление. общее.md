# Метапроект: А3. Обновление

*Метапроект - это декларирование намерений и создание структуры/плана, где каждый отдельный пункт выражен отдельным проектом.*

---

## Цели и проекты

- **про.а3.сети**
	- Цель проекта: создание структуры интернет-/локальных сетей, построенных по единым стандартам, связанных между собой ВПН шлюзами, прокси для обхода блокировок, централизованным управлением и конфигурированием. 
- **про.а3.системы**
	- Цель проекта: полное обновление программного обеспечения, используемого в компании, создание унифицированной системы управления и развёртывания операционных систем, пакетов программ и драйверов. Внедрение политик безопасности, антивирусов, продуманных ACL-прав, а в перспективе - центрилизованного управления через домен.
- **про.а3.сервер**
	- Цель проета: создание единого мощного локального сервера с виртуализацией (Proxmox), в котором будут работать виртуальные машины Windows Server (для домена), Linux (1C), Linux (Wiki, Сайт), Headscale, и который будет также задействован в качестве корпоративного NAS.
- **про.а3.вики**
	- Цель проекта: разворачивание вики-подобного сайта с инструкциями, мануалами и справками для сотрудников.  
- **про.а3.сайт**
	- Создание нового сайта/лендинга с услугами компании, возможностью оставления заявки и справочной информацией для клиентов
