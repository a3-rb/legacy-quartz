# Проект: А3. Сети. Этап 1

---

## Цели проекта

- Цель проекта: создание структуры интернет-/локальных сетей, построенных по единым стандартам, связанных между собой ВПН-шлюзами, имеющих прокси для обхода блокировок, централизованное управление и конфигурирование. В итоге необходимо получить систему, позволяющую осуществлять безпрепятственный файлообмен между филиалами, удалённую работу и доступ к заблокированным ресурсам через прокси.
- На первом этапе создаётся тестовая система, направленная на изучение возможностей, отладки на нескольких базовых компьютерах. В качестве хостового сервера будет использоваться личный сервер Aster, который на 3-м этапе будет замещён на корпоративный.
- Тестовая система будет включать:
	- Сервер Mesh VPN Headscale
	- Публичные конфигурации sing-box нескольких версий:
		- 1. Включающий mesh-vpn
		- 2. Включающий подписки прокси
		- 3. Включающий mesh-vpn и подписки прокси
	- Также будут созданы иные конфигурации для конкретных устройств
- VPN будет настраиваться для следующих задач:
	- Удалённая работа (1с, файлообмен)
	- Объединение локальных сетей филиалов, для файлообмена и доступа к общим ресурсам (единый NAS, сервер 1С, иное)
- Замечу, что выстраивание подобной системы потребует не только создания VPN, но и глубокого изучения нынешней инфраструктуры, особенности 1с, файлообмена windows, ACL, а также создания архитектуры безопасности для дальнейшего развёртывания.
- *Возможно осуществление прямого файлаобмена необязательно, однако можно будет получить доступ по IP (единая IP-структура уже готова). Здесь лучше будет общий NAS, и доступ к конкретным ресурсам. Архитектура безопасности и объеденения будет разрабатываться на втором этапе, пока просто оценка возможностей*
- Проект является частью метапроекта "А3. Обновление"
